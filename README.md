# Cyber Threat Database with Predicted Incident Analysis

A MySQL database project designed to manage organizations, systems, cybersecurity threats, incidents, logs, users, and predicted incident analysis.

## Features

- Organization and system management
- Cybersecurity threat records
- Incident tracking
- System-incident relationships
- Security logs and alerts
- Incident prediction data
- SQL queries using:
  - WHERE
  - BETWEEN
  - IN
  - LIKE
  - IS NULL
  - AND / OR / NOT
  - ORDER BY
  - JOIN
  - GROUP BY
  - HAVING

## Technologies

- MySQL
- SQL

## Database Tables

- Organization
- Systems
- Users
- Threats
- Incidents
- LogsAlerts
- Predictions
- Incident_Systems

## Project Purpose

The project demonstrates relational database design, foreign keys, relationships, data management, and SQL querying for a cybersecurity-focused database system.
